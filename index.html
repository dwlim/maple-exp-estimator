How this is calculated

The rate uses the same OSMS weighted EXP model: map EXP × 3600 ÷ the average spawn cycle. OSMS uses a 7.56-second default spawn cycle when no mob-specific cooldown overrides it. Party size divides the map total evenly between characters.

Party DPS remains visible for comparison, but it no longer limits the rate because the OSMS benchmark is spawn-cycle based. Uptime scales the OSMS benchmark if you want to model downtime.

Monster HP, EXP, and map population defaults are from OSMS Data Explorer. Weighted EXP uses OSMS’s 7.56-second default spawn cycle.
